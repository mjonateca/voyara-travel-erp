# Roadmap

Phase 0 documents architecture and rules. Phase 1 establishes Auth, tenancy, RBAC, app shell and design system. Phase 2 adds Suppliers and Products; Phase 3 Contracting, Inventory and Promotions; Phase 4 Pricing; Phase 5 CRM and Quotes; Phase 6–10 Reservations, supplier confirmation, operations, finance and documents. Phases 11–20 progressively add groups, B2B, connectivity, packaging, B2C, transport, multi-destination, accounting, BI and AI.

Each phase starts with domain/data/API/UI/perms acceptance criteria and ends with lint, typecheck, tests, migration/RLS, isolation, navigation and responsive-theme validation.
