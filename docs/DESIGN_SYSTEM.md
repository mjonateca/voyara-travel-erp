# Design system

Tokens define canvas, surface, elevated glass, ink, muted text, border, accent and semantic status colors for light and dark themes. Components use these tokens: AppShell, GlassPanel, PageHeader, DataTable, StatusBadge, EmptyState, ErrorState and Skeleton.

The visual language is refined hospitality-finance: off-white or midnight canvas, restrained teal accent, compact typography, thin translucent borders, layered soft shadows and glass only on structural surfaces. Blur is restricted to sidebar, top bar, panels, overlays and filters to preserve contrast and performance. Motion is short and reduced-motion friendly.
